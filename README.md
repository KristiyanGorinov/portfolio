# Kristiyan Gorinov — Personal Portfolio

My personal portfolio website: a single-page site that brings together who I am, what I've built, and what I've achieved.

**Live site:** [kgorinov.com](https://kgorinov.com)

---

## Sections

| Section | What's inside |
| --- | --- |
| **Home** | Hero intro with quick links to my awards and a downloadable CV |
| **About me** | Short bio, skills, awards, and education |
| **What else?** | A slideshow of experiences abroad |
| **My Developments** | Projects across Django, JavaScript, 3D modeling (Blender), and presentations |
| **My Hobbies** | Filterable cards (All / Sports / Artistics / Fun & Games): climbing, gym, swimming, salsa, guitar, 3D modeling, games, reading |
| **Blog** | Dated posts about competitions, internships, and other activities |
| **Contact Me** | Contact form for getting in touch |
| **My Skills** | Animated counters for HTML/CSS/JS, Python/Django, 3D modeling, and presentation |

There is also a separate **Awards** page and a downloadable **CV** (PDF).

## Features

- Single-page layout with anchored navigation
- Image slideshow with next/previous controls
- Filterable hobby cards
- Animated skill counters
- Blog-style activity posts
- Contact form
- Responsive layout for desktop and mobile

## Tech Stack

- **HTML5** for structure
- **CSS3** with custom properties for theming
- **Vanilla JavaScript** (no frameworks) for interactivity

## Running Locally

No build step is needed.

```bash
# Clone the repository
git clone https://github.com/KristiyanGorinov/<repo-name>.git
cd <repo-name>

# Option 1: open index.html directly in your browser

# Option 2: serve it locally
python -m http.server 8000
# then visit http://localhost:8000
```
